# D.LAB ONE - 통합 운영 플랫폼 프로토타입

디랩 코딩학원의 통합 운영 시스템 **"D.LAB ONE"**의 클릭형 프로토타입입니다.
캠퍼스 운영, LMS, 콘텐츠 마켓플레이스, 보상 시스템, 결제/정산을 하나의 화면에서 시연할 수 있습니다.

## 바로 실행

브라우저에서 공개 URL에 접속하거나, `index.html`을 더블클릭하면 됩니다.
DB나 서버 설정 없이 단일 HTML 파일로 동작합니다.

## 7개 역할 · 37개 화면

| 역할 | 주요 화면 |
|------|-----------|
| **학생** | 키오스크 출석, 대시보드, 오늘의 수업, 보상 & 상점, 나의 성장 |
| **학부모** | 홈, 카카오 알림톡 피드, 학습 리포트, 아이 성장, 결제 관리 |
| **교사** | 홈, 수업 관리, 녹음 & AI, 리포트 검수, 포인트, 나의 콘텐츠 |
| **원장** | 대시보드, 학생 관리, 출결, 재무, 교실 스케줄 |
| **본사** | 대시보드, 캠퍼스 비교/상세, 로열티 정산, 콘텐츠 검수 |
| **마켓** | 스토어, 콘텐츠 상세(DRM), 장바구니/구매, 등록, 판매자, 정산 |
| **관리자** | LMS 11주 커리큘럼, 동의 관리, 감사 로그 |

## 시연 가능한 5가지 핵심 플로우

1. **학생 출석 플로우** — 키오스크에서 번호 `1842` 입력 → 출석 확인 → 학부모 알림 미리보기
2. **교사 수업 플로우** — 수업 시작 → 녹음 → AI 리포트 생성 → 검수 → 발송
3. **콘텐츠 마켓 플로우** — 스토어 → 상세(DRM 안내) → 장바구니 → 포인트 구매
4. **학부모 포털 플로우** — 알림 확인 → 수업 리포트 → 아이 성장 → 결제 관리
5. **본사 드릴다운 플로우** — 전체 대시보드 → 캠퍼스 상세 → 정산 → 콘텐츠 검수

## 로컬에서 실행

```bash
# 방법 1: 더블클릭
open index.html

# 방법 2: 로컬 서버
python3 -m http.server 8766
# 브라우저에서 http://localhost:8766
```

## 기술 스택

- 순수 HTML / CSS / JavaScript (외부 라이브러리 없음)
- 상태는 localStorage에 저장 (역할 전환, 출석/녹음/구매 상태 유지)
- 우측 상단 "데모 초기화" 버튼으로 언제든 리셋 가능

## 프로젝트 배경

본 프로토타입은 디랩 코딩학원의 다음 RFP 문서를 기반으로 제작되었습니다:

- 1단계: 콘텐츠 보상 마켓 & 공유 커뮤니티
- 2단계: 수업 운영 시스템 (출석, 반 배정, LMS)
- 3단계: 학생 리텐션 B2C 포인트 시스템

콘텐츠 거래 수익 분배(본사 30% / 제작자 70%), 캠퍼스 운영 품질 점수, AI 기반 학습 기록 등 RFP의 핵심 요구사항을 화면으로 구현했습니다.
